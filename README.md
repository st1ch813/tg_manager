# Telegram-бот: розклад, погода, світло

Щодня о 07:00 бот надсилає розклад уроків зі світлом і окремо погоду з порадою, що вдягнути.

## Що вписувати і куди

Ці значення вводяться на Render (Environment), а не в код:

| Змінна | Що вписати |
| --- | --- |
| `BOT_TOKEN` | токен від @BotFather (/mybots, твій бот, API Token) |
| `CHAT_ID` | число, яке бот показує у відповідь на /start |
| `CITY` | Білогородка (для погоди) |
| `STREET` | вул. Володимирська, 58 (лише підпис у повідомленні) |
| `OUTAGE_GROUP` | твоя черга, наприклад 4.2 (перевір на сайті ДТЕК) |

Уроки редагуються у файлі `schedule.json`. Час відправки змінюється у `render.yaml` (SEND_TIME).

## Команди

/start, /today, /schedule, /weather, /light
